## 2. Chỉ dẫn đầu vào cho Task 02B

Task 02B sẽ nối tiếp luồng `ContinuousStreamFrame` từ `continuous_stream.py` vào hệ thống nhận diện sự kiện:
- **TemporalShotFSM (`basketball_scoreboard/shots.py`):**
  Nhận `frame_idx`, `source_time_s`, `ball_obs`, `rim_detections`, `player_observations`, `camera_layout_invalid=is_cut`.
- **PointsEngine (`basketball_scoreboard/points.py`):**
  Khi FSM xác nhận cú ném, gọi `PointsEngine.process_shot` để gán điểm và shooter attribution.
- **ReboundEngine (`basketball_scoreboard/rebounds.py`):**
  Khi FSM phát hiện miss (`rim_hit`, `airball`, `rim_bounce`), gọi `evaluate_missed_shot` với control observations tương ứng.
- **AssistEngine (`basketball_scoreboard/assists.py`):**
  Khi FSM phát hiện made shot, gọi `evaluate_made_shot` với pass events và scorer attribution.
- **EventLedger (`basketball_scoreboard/events.py`):**
  Thu nạp tất cả các sự kiện POINTS, REBOUND, ASSIST vào ledger thống nhất với lifecycle causal.
- **BoxScoreEngine (`basketball_scoreboard/boxscore.py`):**
  Tổng hợp box score từ EventLedger.
- **Heatmap Generator (`basketball_scoreboard/heatmap.py`):**
  Xuất bản đồ nhiệt (nếu chưa calibrated thì xuất diagnostic mode rõ ràng).
- **Cập nhật CLI `run_demo.py`:**
  Kích hoạt mode `--mode video-analysis` thực sự gọi pipeline continuous này thay vì báo lỗi chưa hỗ trợ.
